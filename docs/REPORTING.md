# Reporting and exports

All reports are generated by branch-scoped, permission-checked RPCs. The client
does not aggregate authoritative financial data.

| Report | RPC | Inputs |
| --- | --- | --- |
| Executive dashboard | `report_dashboard` | branch |
| Sales | `report_sales` | branch, date range |
| Inventory valuation | `report_inventory` | branch |
| Production | `report_production` | branch, date range |
| Profit and loss | `report_profit_and_loss` | branch, date range |
| Receivables | `report_receivables` | branch |
| Payables | `report_payables` | branch |
| Rentals | `report_rentals` | branch |
| Payroll | `report_payroll` | payroll run |
| Supplier statement | `supplier_statement` | branch, supplier, dates |
| Full branch export | `export_branch_data` | branch |

## Screen

**Reports & analytics** provides a report picker, date range, run/refresh, CSV
export and branded PDF export. Payroll reports use the latest payroll run; the
full branch export returns JSON and is intended for migration/backup review.

## CSV

`flattenReport` converts nested JSON into rows and `rowsToCsv` writes a stable
header. On mobile/desktop the file is written to the temporary directory; on web
the CSV is copied to the clipboard.

## PDF

`lib/data/pdf_export.dart` builds A4 documents with:

- official logo and business name/slogan header,
- branch name, document title/number, issue date,
- detail block, party block, item/line table,
- totals box and note,
- gold rule and page numbers,
- green/cream/gold brand palette.

Branded PDFs are available for POS receipts, sale receipts, rent invoices,
payslips and any report. The file is shared through the platform share sheet;
desktop platforms without a share sheet still receive the generated document
through the configured share plugin.

## Accounting notes

- Dashboard revenue and P&L are based on completed sales and recorded
  expenses/payroll/cash movements.
- Voided sales and completed returns are excluded/negative as appropriate.
- Inventory value uses the stock ledger and item cost.
- Payroll net totals are stored on the run; payslips are immutable snapshots.
- Always reconcile report totals against the cash close and supplier/tenant
  statements before filing.
