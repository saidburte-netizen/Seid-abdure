# Brand identity

## Official mark

- Source: `app-icon-1024.png` uploaded by the business.
- Runtime asset: `assets/branding/logo.png` (1024×1024, RGB).
- Never redraw, recolour, crop or replace the official mark with a generated
  imitation. If a new official file is issued, replace the asset and regenerate
  icons/splash.

## Name and slogan

- Business name: **Brade and Cake House**
- Slogan: **hani brade and cake**
- Constants: `lib/brand/brand.dart`

## Launcher icons

`flutter_launcher_icons` generates Android (including adaptive), iOS, web,
Windows and macOS icons. The Android adaptive foreground is
`assets/branding/icon_foreground.png`: the official logo centred at 66% of a
transparent 1024 canvas, with background `#F4E8D8`. iOS icons are opaque
(`remove_alpha_ios: true`).

Regenerate after replacing the logo:

```sh
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

## Notification icon

`assets/branding/notification_icon.png` is a white monochrome silhouette
derived from the official mark on transparency. It is copied to
`android/app/src/main/res/drawable/notification_icon.png` and referenced by the
Firebase notification metadata with brand gold `#C9A227` as the accent colour.

## Splash

Native splash uses `#F4E8D8` in light mode and `#06210F` in dark mode, with the
official logo. Android 12 splash and iOS launch images are generated by
`flutter_native_splash`.

## Platform names

- Android label, iOS display/name, web title/manifest, Windows title,
  Linux window title and macOS product name: **Brade and Cake House**.
- Web short name: **Brade & Cake**.

## Documents

Receipts, invoices, payslips, statements and report exports use the same logo,
name, slogan and palette in `lib/data/pdf_export.dart`.
